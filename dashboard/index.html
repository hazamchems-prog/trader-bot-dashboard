Quand le robot attend ta validation

Comment savoir que le robot attend sur toi :

1. Tu reçois une notification Grok (ou un message dans le chat) avec le titre du type « Proposition de trade – validation requise ».
2. Sur ce Dashboard, la carte « Statut bot » passe de « Prêt » à « En attente de validation » et le nombre d’ordres en attente devient 1, 2…
3. Les détails du trade (paire, direction, lot, SL, TP) apparaissent dans la section « Ordres en attente ».

Tant que tu n’as pas répondu « oui » / « valider » / « placer », aucun ordre n’est envoyé à MetaTrader 5.

Comment utiliser le bot + MT5

  1. Le bot (skills trader-*) propose des idées et calcule les tailles → fichiers dans trader/.
  2. Tu valides chaque ordre manuellement (jamais d’exécution auto).
  3. Sur MT5 : tu places l’ordre avec le lot exact calculé + Stop Loss + Take Profit.
  4. Règle absolue : si le calcul donne un risque > 50 € → on réduit le lot ou on passe.
  5. Paper trading obligatoire jusqu’à ce que tu sois à l’aise avec le process.
