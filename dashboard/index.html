Comment le robot + toi fonctionnent ensemble

  1. Le robot analyse le marché et propose des idées avec lot déjà calculé pour ≤ 50 € de risque.
  2. Les alertes sont visibles ici et transmises au robot.
  3. Tu valides manuellement chaque ordre (jamais d’exécution auto).
  4. Sur MT5 : tu places l’ordre avec le lot exact + Stop Loss + Take Profit.
  5. Si le calcul dépasse 50 € de risque → on réduit le lot ou on passe.
